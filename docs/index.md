# sreg 2.1.0 documentation

`sreg` estimates average treatment effects in stratified randomized
experiments. It is the pure-Python counterpart of the R `sreg` 2.1.0 package.

- [Practical guide](getting-started.md): the Python version of the R package's
  introductory vignette.
- [API reference](api.md): complete public signatures, parameters, result
